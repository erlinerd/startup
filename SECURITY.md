# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Email [security@erlinerd.com](mailto:security@erlinerd.com) or reach out
privately via [erlinerd.com](https://erlinerd.com). You should receive a
response within 48 hours. If the issue is confirmed, we will release a fix
as soon as possible, depending on complexity.

## Supported versions

| Version  | Supported |
| -------- | --------- |
| latest   | ✅        |
| < latest | ❌        |

## Disclosures

This template is a starter — treat all demo code (waitlist form, sample
routes, example schema) as untrusted-by-default until you replace it with
your own logic.
